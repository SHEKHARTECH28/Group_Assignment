## Project Description

This project is a Python Calculator Application developed collaboratively using Git and GitHub. The purpose of this assignment was to understand and implement GitHub collaboration features such as repository creation, branching, committing changes, pushing code, creating Pull Requests, reviewing code, and merging contributions into the main branch.

Each calculator operation was implemented in a separate branch by a team member and later merged into the main branch through Pull Requests.

---

## Calculator Operations

The calculator supports the following operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Power
6. Modulus
7. Floor Division

## Git Workflow Followed

1. Team Leader created the GitHub repository.
2. Repository link was shared with all team members.
3. Each member cloned the repository to their local machine.
4. Separate branches were created for assigned operations.
5. Team members implemented their respective operations.
6. Changes were committed and pushed to GitHub.
7. Pull Requests were created for each branch.
8. Pull Requests were reviewed and approved.
9. All branches were merged into the main branch.
10. Final calculator application was tested successfully.
